Design Team Contributions

Embedded Transmission Data Acquisition (25/26)

Description

This project involved learning how to write firmware on STM32 chips to collect real-time temperature data from the vehicle's transmission system. Additionally, I assisted in migrating the vehicle's existing CAN bus communication library to use FreeRTOS.

What I learnt

  • How to program STM32 boards and contribute new firmware to an existing codebase
  • How the CAN bus protocol works and how FreeRTOS can be used instead of polling to guarantee predictable response times when collecting data from the sensors during competition

CVT Modelling and Manufacturing (22/23)

Description

This project involved designing and manufacturing a Continuously Variable Transmission (CVT) system for the team's 2024 vehicle. The CVT uses a pulley-and-belt mechanism to provide seamless gear-ratio transitions and keep the engine operating in an effective RPM range. Components were designed in CAD and manufactured using precision machining processes, including Mastercam-programmed lathe operations.

Key Contributions

  • Assisted with CAD modelling and manufacturing work for the CVT system
  • Shadowed the manufacturing of the secondary transmission unit's sheaves
  • Learned to compose G-code toolpaths with Mastercam for CNC machining
