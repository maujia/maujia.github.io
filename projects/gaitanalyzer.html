Hardware Gait Analyzer

Prototype motion analysis tool

Description

Custom wireless sensor modules using ESP32s and 6-axis IMUs to measure simple hip flexion and extension movements.

Technical Details

  • Collecting angle data in real time via bluetooth using a 3rd ESP32 as a receiver plugged into a computer.
  • IMU angle data filtered using a Madgwick filter (quaternion based) and exponential smoothing.
  • Analyzed the data by looking at the peak angle values and steadiness with Python & SciPy.
