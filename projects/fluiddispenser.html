Automated Fluid Dispenser

Group Project

Description

A hands-free fluid dispenser prototype. Inspired by Vancouver's pilot project machine called MySafe.

Key Features

  • Custom 5-gear gearbox and 3D-printed housing.
  • 167:1 high-torque gear ratio for precise vial alignment.
  • Hands-free operation using IR sensors.
